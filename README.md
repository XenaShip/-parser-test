# Парсер контактных данных сайта
парсер, который обходит страницы сайта внутри одного домена и собирает контактные данные:

- e-mail адреса
- телефонные номера

_____________________________________________________________

Оисание задачи:

Необходимо реализовать парсер, который:

- принимает стартовый URL сайта
- обходит страницы сайта (не только главную)
- работает только внутри одного домена
- извлекает контактные данные (email и телефоны)
- возвращает результат строго в формате:

json
{
  "url": "https://shipxena.com",
  "emails": ["shipxena@example.com"],
  "phones": ["+79260000000"]
}

!!Если данные не найдены — возвращаются пустые списки!!
_________________________________________________________________________
Реальные сайты, на которых я прверяла работу парсера:

Парсер был протестирован на нескольких реальных ресурсах:

- https://acs.com.ru/ успешно извлекаются e-mail и телефонные номера  
- https://www.iana.org/about/contact/ успешно извлекаются телефонные номера  
- https://baza.drom.ru/ сайт использует антибот-защиту и может не отвечать на обычные HTTP-запросы; парсер корректно обрабатывает таймаут (не падает и возвращает пустой результат)



Что делает мой парсер?
____________________________________________________________
Основной функционал:

скачивает HTML страницы через requests

извлекает ссылки через BeautifulSoup

корректно обрабатывает относительные ссылки (/about)

обходит только страницы одного домена

собирает контакты через регулярные выражения

устойчив к ошибкам сети и плохой HTML-разметке

защищён от бесконечного обхода лимитом страниц

Почему имено такое решение?
__________________________________
-Обход только одного домена: используется urlparse, чтобы парсер не уходил на внешние сайты.
-Защита от бесконечного обхода: введён лимит max_pages.
-Поддержка относительных ссылок: применяется urljoin.
-Фильтрация мусорных ссылок: исключаются mailto:, tel:, #fragment, query-ссылки.
-Устойчивость к ошибкам: запросы обёрнуты в try/except, используется timeout.
-Удаление дубликатов: контакты собираются через set.
-Снижение false positives: телефоны проходят строгую фильтрацию, чтобы не считать технические числа телефонами
